# BlackTiger Tools

A comprehensive penetration testing and security tool with 40+ modules for network scanning, OSINT, phishing, malware generation, Discord tools, and more.

## Features

- Network Scanner (Vulnerability, Info, URL, IP, Port, Ping)
- OSINT (Doxing, Tracker, EXIF, Dorking, Username/Email/Phone lookup)
- Utilities (Phishing, Password cracking/encryption, Database search, Dark Web links)
- Virus Builder (RAT, Malware, Stealer, Keylogger, Ransomware)
- Discord Tools (Token, Bot, Webhook, Nitro)
- Roblox Tools (Cookie login, User info)
- Cross-platform (Windows/Linux)
